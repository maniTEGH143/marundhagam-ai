# Marundhagam AI — Free Hackathon Product

Open `app/index.html` in a modern browser.

Included:
- responsive mobile/desktop product UI
- medicine search/profile
- prescription upload workflow
- duplicate detection demo
- interaction-screening architecture
- AI assistant demo
- Tamil/English-ready UI
- My Medicines
- Trust Center
- safety-first disclaimers

This is a free hackathon prototype. Medical records and safety rules are placeholders and must be replaced by authoritative, reviewed data before clinical use. Real OCR/LLM hosting is intentionally not required for the free demo.
