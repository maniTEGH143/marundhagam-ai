# Deploy Marundhagam FREE — GitHub Pages

This is a static web app, so GitHub Pages can host it for free.

## Steps
1. Create/sign in to a GitHub account.
2. Create a **public** repository, e.g. `marundhagam-ai`.
3. Upload `index.html`, `README.md`, and `docs/`.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`.
7. Save.
8. GitHub will show a public `github.io` URL.

Then open that URL on your phone. No ZIP extraction is needed.

## Important
This static version is a hackathon/demo product. It does not contain a real clinical OCR service or production medical database. Do not use it for medication decisions.
