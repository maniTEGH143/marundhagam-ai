How Marundhagam knows

The intended production pipeline is verified knowledge → retrieval → safety rules → AI explanation → citation. Current records are explicitly demo placeholders.

Important: Demo data is not clinical evidence. Do not use this prototype to make medication changes.

✓ Verified fact

Structured information backed by an approved source in the production system.

✦ AI explanation

Plain-language response generated only from retrieved context.

⚙ Safety rule

Deterministic screening result with rule ID, evidence and review metadata.

Evidence model

Medicine sourceSource identifier · evidence level · last reviewed · database version
Interaction sourceInteraction pair · severity basis · evidence · review status
AI provenanceRetrieved records · model response · citation objects · abstention when evidence is insufficient
